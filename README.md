# 🏍️ Moto GP Racing Game
This project is a motorcycle racing game. You just need to enter the number of racers, the brand of motorcycle, the racer's name, and the registration number to race against each other and win the championship. 
This game is for all ages; anyone can play.

## 🌟 Main features
* **Register Racers:** Add any number of racers to the tournament [cite: 2].
* **Diverse Brands:** Supports creating various car models from popular brands: `Ducati`, `Yamaha`, `Honda`, `Aprilia` [cite: 2, 5, 6, 7, 10].
* **Race Simulation (Formation Lap):** Displays racer information along with a random starting speed (from 300 to under 350 km/h) [cite: 8].
* **Opening Lap:** Arranges and displays the leaderboard of racers based on decreasing speed [cite: 2].
* **Champion Recognition:** Automatically finds and displays the fastest racer (Champion) [cite: 2].
* **Console Effects:** Integrates a real-time countdown timer and a vibrant ASCII Art interface [cite: 2, 4].

## 🛠️ Technology used
The project is written in Java programming language 
Using IntelliJ IDEA 2026.2.3 and Amazon Corretto JDK 21.0.12. 
The project does not use any database management systems or connect to databases.
